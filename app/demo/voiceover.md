# Voice-over

The film is a walk through the Studio: Grzegorz on camera, then the screen. One voice at a time, about 110 words.
Music ducks under every line (`voice` in `cut.json`). The intro is spoken on camera; the rest goes to
`footage/vo/<name>.wav`, recorded dry, mono, 48 kHz. The captions in `cut.json` already say which model does what,
so the voice can stay short.

| at | file | line |
|---|---|---|
| 0:04 | on camera | I'm Grzegorz. Diorama turns an idea, a few photos or a video into a painted adventure game you can play. It runs on Meta's Muse models and SAM. Here's how. |
| 0:26 | ask.wav | Before it builds, Diorama asks what it can't guess. In pictures. |
| 0:37 | build.wav | Then it builds the whole game, and a bot plays every ending before I do. |
| 0:57 | how.wav | Muse Spark plans each place. Muse Image paints it. SAM cuts out everything you can touch, depth gives the floor and the scale, so the cut-outs float like a real diorama. The hero is painted walking, then gets a 3D body and a skeleton. |
| 1:49 | change.wav | Want something different? Click it, paste a screenshot, ask. Muse Code changes the world, and Undo takes it back. |
| 2:11 | export.wav | One zip. Any browser. |
| 2:35 | end.wav | Diorama. Open source. Go build the game you dreamed of. |

The cold open, the build's last seconds and the game itself have no voice.
