# Diorama one-pager

The landing page served at https://grzegorz.tanczyk.pl/diorama/. Plain static HTML, no build step.

Deploy: copy `index.html` and `media/` into `diorama/` of the gtanczyk.github.com repo (GitHub Pages for grzegorz.tanczyk.pl). Each published world goes next to it as `diorama/<slug>/`, made with `diorama export <slug> --home ../` (the `← Diorama` link in the corner leads back to this page) and unzipped there.
